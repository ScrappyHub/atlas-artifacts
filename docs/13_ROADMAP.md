# Roadmap

## Phase 1 (Windows MVP)
- Agent service + UI
- Engine: windows.winget
- Inventory + scan + notify + manual apply
- Full run artifacts

## Phase 2 (Safe Auto)
- Scheduling + constraints
- Silent installs where supported
- Rollback/restore strategies
- Append-only artifact store + hash-chain

## Phase 3 (Cross-platform)
- macOS: brew engine
- Linux: apt/dnf engine
