# Vision

Atlas Update makes keeping a PC up-to-date effortless, safe, and accountable.

## Principles
1. User control first
   - A user can always choose: NEVER update automatically.
2. Safety over convenience
   - Only trusted sources. No scraping, no random EXEs.
3. Auditability as a product feature
   - Every run emits artifacts: inventory, plan, apply logs, verification.
4. Capability gating everywhere
   - Engines declare capabilities; policies decide what can execute.
5. Least privilege
   - Elevation is explicit, scoped, and recorded.
